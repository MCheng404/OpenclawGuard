# OpenclawGuard UI 重设计规格说明

日期: 2026-05-28
状态: 已确认

## 目标

全面翻新 OpenclawGuard Qt6 桌面应用的 UI，包括视觉风格、信息架构、交互体验三个维度。

## 技术约束

- 框架: Qt6 Widgets (C++)
- 编译器: LLVM-MinGW 17.0.6 (Clang)
- Qt 版本: 6.11.1 llvm-mingw_64
- 图标集: Lucide Icons (SVG, 通过 Qt6Svg 渲染)
- 构建系统: CMake + Ninja
- 文件位置: D:\Open\OpenclawGuard\src\

## 1. 信息架构

### 导航重构: Tab → 侧边栏

侧边栏宽度 200px，固定左侧，结构如下:

```
侧边栏
├── 仪表盘 (Dashboard)        ← 新增
├── ───────────── (分隔线)
├── 网关管理
├── 进程守护
├── ───────────── (分隔线)
├── 更新管理
├── 环境检测
├── ───────────── (分隔线)
├── 设置
```

侧边栏底部固定:
- 主题切换按钮 (Lucide `sun` / `moon` 图标)
- 版本号文字 `v1.0.0`

### 底部状态栏替换事件日志

底部 28px 状态栏:
- 左侧: 最后一条事件消息 (滚动单行)
- 右侧: 网关状态指示点 + 端口号

事件日志从底部表格移入各页面内部 (Dashboard 时间线 / 网关页日志按钮)。

## 4. 页面布局详细

### 4.1 Dashboard (新增)

- 3 个状态卡片并排: 网关状态 / 守护进程 / 可用更新
- 卡片高度 120px, 内含 Lucide 图标 + 标签 + 数值大字 (24px bold) + 描述文字
- 网关在线时绿色图标带 CSS 脉冲动画
- 快捷操作按钮组: 启动网关 / 停止网关 / 检查更新
- 事件时间线: 左侧 2px 竖线 + 6px 圆点, 最近 10 条, 自动滚动

### 4.2 网关管理

- 页面标题 + 描述
- 网关配置卡片: CLI 路径输入 + 浏览按钮, 端口输入
- 控制面板卡片: 状态指示 (在线/离线), 进程信息 (PID, 内存), 操作按钮组 (启动/停止/重启/日志)
- 端口监控卡片: 检测间隔 / 失败阈值 / 健康检查路径

### 4.3 进程守护

- 操作按钮栏: 浏览添加 / 从进程选取 / 移除 (未选中时置灰)
- 表格: 开关图标 (●/○) + 名称 + 路径 + 状态标签
- 状态标签: "运行中" (绿色) / "已停止" (红色)
- 检测间隔配置: 右下角数字输入

### 4.4 更新管理

- 操作栏: 检查更新按钮 + 通道下拉框
- Openclaw CLI 卡片: 当前版本 vs 最新版本, 有更新时显示下载按钮
- 下载进度条: 点击下载后显示
- GitHub Releases 表格: 版本 / 类型标签 / 日期

### 4.5 环境检测

- 操作栏: 检测环境 / 检查最新版本 (加载时禁用 + 旋转图标)
- 表格: 环境名 / 当前版本 / 最新版本 (有新版本红色高亮 + "↑ 更新"链接)
- 点击行在表格下方展开路径详情

### 4.6 设置

- 外观分组: 主题下拉 / 强调色调色板
- 行为分组: 开机自启 / 启动最小化 / 崩溃重启
- 日志分组: 保留天数 / 清空日志 (带确认弹窗)

## 5. 交互与动画

### 动画

- 侧边栏导航指示条滑动过渡 (300ms ease)
- 卡片 hover 上浮 2px + 阴影加深 (200ms)
- 按钮按下态缩放 0.97
- 网关在线状态脉冲动画 (2s 循环, opacity 1.0 → 0.4 → 1.0)

### 加载状态

- 网络请求时按钮显示旋转图标 + 禁用
- 表格数据加载时显示骨架屏
- 版本检查中显示旋转图标

### 空状态

- 守护列表空: 居中插图 + "暂无守护进程" + 添加按钮
- 更新列表空: "暂无可用更新"
- 环境检测未执行: "点击检测环境开始"

### 反馈

- 成功: 底部状态栏绿色提示
- 失败: 红色提示 + 错误详情
- 删除/清空: 模态确认对话框
