# OpenclawGuard PyUI UAT 验收清单

> 测试目标：验证 PyQt-Fluent-Widgets 重构版本在核心流程上可用、稳定、可回退。

## A. 启动与基础

- [ ] 双击 `run-pyui.bat` 可正常启动程序
- [ ] 首屏无崩溃、无明显报错弹窗
- [ ] 页面导航（仪表盘/网关/守护/更新/环境/设置）可切换

## B. 网关管理

- [ ] 网关状态可刷新并显示（运行中/未启动）
- [ ] 点击“启动网关”后状态变为运行中（或明确失败提示）
- [ ] 点击“停止网关”后状态变为未启动（或明确失败提示）
- [ ] 点击“重启网关”后状态恢复为运行中（或明确失败提示）

## C. 设置持久化

- [ ] 在“设置”页修改 CLI 路径并保存后，重启应用仍保留
- [ ] 修改网关端口并保存后，重启应用仍保留
- [ ] 修改 GitHub Token 并保存后，重启应用仍保留
- [ ] `build-release\OpenclawGuard.ini` 对应键值正确更新

## D. 进程守护

- [ ] 添加守护项（名称+exe路径）成功
- [ ] 列表中可看到新增项，且可刷新状态
- [ ] 选中项可启用/禁用切换
- [ ] 选中项可删除
- [ ] 表格直接编辑后点击“保存表格修改”可落盘
- [ ] 重启应用后守护项仍存在（持久化生效）

## E. 更新管理

- [ ] “检查更新”可返回 dry-run 结果
- [ ] 表格展示当前版本/通道/目标规格/结果
- [ ] 点击“执行更新”会出现二次确认弹窗
- [ ] 取消时不执行；确认时执行并给出结果提示

## F. 环境检测

- [ ] 点击“开始检测”后生成组件列表
- [ ] Node/npm/Python/Git/Openclaw/qmake 显示版本与安装状态
- [ ] 检测时间戳更新

## G. 回归与稳定性

- [ ] 连续启停网关 5 次无崩溃
- [ ] 连续刷新守护/环境/更新 10 次无卡死
- [ ] 关闭后重新打开，状态与配置一致

## H. 阻塞问题记录

- [ ] 若失败，记录步骤、实际结果、期望结果、截图、时间

---

## 验收结论

- [ ] 通过（可进入灰度）
- [ ] 有条件通过（需修复 P2/P3）
- [ ] 不通过（存在阻塞性问题）
